# Freedom Year

A lightweight retirement timeline calculator built with the **Lumina** design system.

## Features
- Live sliders for age, savings, contributions, return rate, and desired monthly income
- Instant projection of "Freedom Year" (when work becomes optional)
- Elegant, light-mode experience inspired by Sunday mornings

## Tech
- Vanilla HTML/CSS/JS
- No dependencies, deploy anywhere (GitHub Pages ready)

### Local Development
```bash
cd freedom-year
python3 -m http.server 3000
```
Visit `http://localhost:3000`.
